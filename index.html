🔑 How to get a Google Gemini Key:

  1. Go to the Google AI Studio Key Page.
  2. Sign in with any standard Google Account.
  3. Click "Create API Key" and copy it.

⚡ How to get a Groq Key:

  1. Go to the Groq Console.
  2. Sign up or sign in, then navigate to the API Keys tab on the left.
  3. Click "Create API Key", name it, and copy it.
